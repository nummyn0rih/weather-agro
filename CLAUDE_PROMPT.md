# 🤖 Шаблон промпта для Claude Code

> Этот файл содержит готовые промпты для работы с Claude Code на проекте Weather Agro.
> Используй их в начале каждой сессии и при постановке конкретных задач.

## 📌 Стартовый промпт (в начале каждой сессии)

```
Ты работаешь над проектом Weather Agro — веб-приложение для мониторинга
погоды в агрохозяйстве.

**Контекст проекта:**
- Полная спецификация: см. PRD.md
- План задач: см. TASKS.md
- Стек: FastAPI + PostgreSQL/TimescaleDB + React/TS + Tailwind + shadcn/ui
- Деплой: Docker Compose на VPS

**Принципы работы:**
1. Перед началом задачи — прочитай PRD.md и TASKS.md
2. Каждая задача относится к одному из слоёв:
   - 🔧 BE  — Backend / Логика
   - ⚙️ FE-F — Frontend / Функциональный (без визуальной стилизации)
   - 🎨 FE-V — Frontend / Визуальный (только стили, логику не трогать)
   - 🚀 INFRA — Инфраструктура / DevOps
3. Не смешивай слои в одной задаче.
4. Соблюдай Definition of Done из TASKS.md (раздел 17.3 PRD.md).
5. Не добавляй фичи, которых нет в задаче — только то, что просили.
6. Если что-то непонятно — задай уточняющий вопрос ДО начала работы.

**Стандарты кода:**
- Python: PEP 8, type hints везде, async/await для I/O, Pydantic v2
- TypeScript: strict mode, без any, функциональные компоненты + хуки
- Все эндпоинты — с Pydantic-схемами и документацией для Swagger
- Тесты: pytest для backend, минимум один happy path на эндпоинт

**Готов к задаче?** Жди команду в формате:
"Выполни задачу X.Y из TASKS.md"
```

## 📌 Промпт для конкретной задачи (Frontend Visual)

```
Выполни задачу <НОМЕР> из TASKS.md (слой FE-V).

**ВАЖНО:** Это задача ТОЛЬКО на стилизацию.
Логика, разметка структуры, обработчики событий — НЕ ИЗМЕНЯЮТСЯ.

**Перед началом:**
1. Убедись, что функциональная версия (FE-F) уже работает
2. Прочитай требования к стилю в PRD.md (раздел 2.3) и в задаче TASKS.md
3. Изучи дизайн-токены в `src/styles/tokens.css`

**Стили:**
- **Apple HIG** (для дашборда, графиков, аналитики):
  - Скругления 16–20px
  - Мягкие тени (multiple layers)
  - Шрифт Inter (вместо SF Pro)
  - Акцент: системный синий #007AFF + пастельные
  - Крупные отступы, чёткая иерархия типографики
  - Поддержка светлой и тёмной темы (как iOS)

- **Notion-style** (для таблиц, журнала, настроек, алертов):
  - Минимализм, тонкие границы
  - Плотная компоновка
  - Inter, моноширинный для чисел
  - Hover на строках/блоках с лёгким фоном
  - Sticky headers, чипы для фильтров

**Что от тебя нужно:**
1. Применить стили согласно DoD из TASKS.md
2. Поддержка светлой и тёмной темы
3. Адаптивность сохранена
4. Skeleton loaders в нужном стиле
5. Плавные hover/focus переходы

**Чего НЕ делать:**
- НЕ менять логику компонентов
- НЕ менять API-запросы
- НЕ менять структуру JSX (только классы и обёртки для стилизации)
- НЕ добавлять новые зависимости без согласования

**В конце:**
- Покажи diff (только стили и классы должны измениться)
- Скриншоты до/после в светлой и тёмной теме
- Скриншоты на mobile (360px) и desktop
```

## 🎯 Best practices

1. **Одна задача — одна сессия.** Не пытайся в одном чате сделать 5 задач сразу.
2. **Сохраняй контекст.** В начале новой сессии — обязательно стартовый промпт.
3. **Проверяй DoD.** После завершения задачи — пройдись по чек-листу из TASKS.md.
4. **Коммить часто.** Каждая выполненная задача = отдельный коммит с понятным сообщением.
5. **Не доверяй слепо.** Запускай тесты, проверяй вручную через Swagger / UI.
6. **Документируй.** Если делаешь нестандартное решение — добавь комментарий.

## 📞 Если что-то пошло не так

**Claude Code зашёл в тупик / делает не то:**
1. Останови выполнение
2. Перечитай задачу — корректна ли постановка
3. Дай дополнительный контекст
4. Если не помогает — начни новую сессию со стартовым промптом

**Задача оказалась слишком большой:**
1. Разбей на подзадачи
2. Обнови TASKS.md
3. Делай по одной

**Появились новые требования:**
1. Сначала обнови PRD.md
2. Потом обнови TASKS.md
3. Только потом приступай к коду
